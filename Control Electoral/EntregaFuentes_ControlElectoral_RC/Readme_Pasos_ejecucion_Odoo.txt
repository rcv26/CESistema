Pasos para la instalacion y ejecucion de Odoo CE - Modulo de Control Electoral

1.- Descargar e Instalar Odoo 14 CE
2.- Copiar Carpeta Custom dentro de la carpeta odoo //Ejemplo C:\Odoo14\odoo\custom
3.- Restaurando el servicio Odoo
4.- Ejecutar http://localhost:8069 ,configurar Odoo 14 CE por primera vez (Creacion de Base de Datos, Setear Master Password, etc)
5.- Una vez ejecutado Odoo 14 CE sin problemas Ingresamos al Manager Database, seleccionar Restore Database y procedemos a
restaurar la base de datos que fue entregada con la informacion de las elecciones. (formato zip)
6.- Ingresar al Sistema de Control Electoral con el usuario: admin@electoral.com contrasena: 12345
Master Password: 12345

7.- Listo ya esta dentro del Sistema de Control Electoral
